Distributed Systems
Distributed Key-Value Cache with Replication

In-memory distributed cache across three nodes — one primary, two replicas — with asynchronous replication, eventual consistency, node health monitoring, failure handling and full data re-synchronization after node recovery. Inter-node communication over HTTP. Designed to demonstrate fault tolerance under replica failure scenarios. 

Client (read/write)
      │
      ▼
Primary Node  ←  write authority
      │  async replication
      ├──────────────────▶ Replica 1
      │                         ↑ health check / resync on recovery
      └──────────────────▶ Replica 2
                                ↑ health check / resync on recovery

Failure path: primary detects replica down → marks stale
              replica recovers → full sync from primary state
